# Job Searching Agent V3

Targeted job-family search agent.

Targets Data Analyst, BI/Power BI, HR Data/People Analytics, Data Governance/Data Quality, Reporting, Data/Analytics Consulting and data-focused Functional/Business Analyst roles. Data Engineering/ETL is treated as a stretch family.

Pipeline: real career pages -> individual vacancy -> target-title validation -> hard requirements -> profile score -> CSV.

V3 rejects internships, finance-focused analyst roles, mandatory Master's requirements without equivalent-experience wording, and mandatory specific technical degrees without equivalent wording.
